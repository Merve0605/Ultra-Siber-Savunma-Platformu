# Ultra-Siber-Savunma-Platformu
CipherGuard, siber güvenlik süreçlerini bireysel ve kurumsal kullanıcılar için basitleştiren modern bir web platformudur. Biyometrik parmak izi doğrulama , interaktif yapay zeka asistanı ve Firebase entegrasyonu içerir. Tailwind CSS ile geliştirilmiş, kullanıcı dostu ve responsive tek sayfalı bir siber savunma panelidir.
